# XianxiaRogue 游戏设计框架 v0.1

> 状态：玩法部分为设计假设 / 待验证。首轮单机、先完成 V0 生产工作流基线已确认。

## 1. 一句话定位

一款首轮按单机验证的 45° 俯视角修仙动作 Rogue-lite：玩家进入不断变化的秘境，以高机动剑修战斗形成一局独有的“道”，把战利品带回可见、可经营的个人洞府，并用洞府的新能力开启下一次更深的探索。最终产品是否扩展多人仍未定案。

核心记忆点：**修的是一条道，养的是一座洞府。**

## 2. 玩家承诺

- 十秒内：移动、闪避、攻击都足够直接，第一击就有命中感。
- 三分钟内：出现第一次足以改变打法的悟道选择。
- 十分钟内：完成一次包含杂兵、精英、首领和回府兑现的短循环。
- 多局之后：洞府会真实地展示玩家带回了什么、选择修了什么，而不只是菜单里的升级数字。

## 3. 设计支柱

1. **动作先于数值**：胜负首先由观察、走位、闪避时机和招式选择决定。
2. **构筑必须改变行为**：优先改变攻击形态、位置关系、触发条件和资源循环，少做纯百分比增伤。
3. **战斗—选择—兑现三拍循环**：一间房负责制造压力，房间结束负责做选择，回洞府负责兑现长期意义。
4. **怪物负责制造场面**：敌人要有夸张轮廓、清晰前摇和可被玩家反制的强招，不靠单纯堆血量。
5. **失败也推动下一局**：局内功法归零，但关键研究材料可以保留；通关额外奖励，不做全损失惩罚。
6. **洞府是空间，不是表格**：设施升级需要有模型、功能和角色/环境变化，玩家能看见成长留下的痕迹。

## 4. 三层循环

| 层级 | 时长 | 玩家行为 | 主要反馈 |
|---|---:|---|---|
| 战斗微循环 | 3–20 秒 | 读前摇 → 走位/闪避 → 连招 → 破势 → 处决 | 停顿、击退、音效、镜头与掉落吸附 |
| 单局循环 | 8–20 分钟 | 选路线 → 清房 → 悟道 → 精英 → 首领 → 归府 | Build 成形、场面升级、稀有战利品 |
| 洞府循环 | 20–60 分钟 | 投入材料 → 建/升级设施 → 解锁新选择 → 再入秘境 | 可见空间成长与下一局新策略 |

闭环为：

**洞府整备 → 进入秘境 → 战斗掉落 → 悟道构筑 → 击败首领/战败回归 → 建设洞府 → 解锁新打法 → 再次出发**

## 5. 首轮战斗模型

### 5.1 视角与操控

- 固定约 45° 俯视角，镜头不允许玩家自由旋转，先保证空间判断稳定。
- 键鼠采用 WASD 移动、鼠标指向；手柄采用左摇杆移动、右摇杆辅助朝向。
- 角色移动与朝向解耦，攻击允许短时间自动吸附，但不替玩家跨越错误距离。
- 屏幕信息优先级：玩家位置 > 敌人前摇 > 危险区 > 掉落 > 环境装饰。

### 5.2 首把武器：本命飞剑

本命飞剑同时提供近战连击与中距离御剑，作为修仙题材区别于普通近战 Rogue-lite 的第一张名片。

- **剑诀 / 普攻**：三段近战连击，第三段产生明显击退或破势。
- **御剑 / 特殊攻击**：飞剑向目标方向射出并返回；去程与回程均可命中，鼓励玩家调整站位。
- **身法 / 闪避**：短距离无敌位移，可取消普攻后摇，但有连续使用限制。
- **剑意**：攻击与精准闪避积累；满后强化下一次御剑，首个 DEMO 不增加独立终极技能按键。

### 5.3 命中感组成

- 轻击以音效、受击闪白和小幅击退为主。
- 重击/处决增加短命中停顿、镜头冲击、残影和更强音频低频。
- 强敌不能被无限击退；改为削减“定力”，破势后提供短爆发窗口。
- 所有高伤敌招必须同时具备轮廓、颜色、音效三类预警中的至少两类。

### 5.4 悟道构筑

首轮使用三条法则，每条法则都能改造普攻、御剑或身法：

- **炎**：附着灼烧，叠层后引爆，擅长清群。
- **雷**：在目标间传导，精准闪避可触发落雷，擅长节奏爆发。
- **剑**：留下剑痕，回程御剑触发剑痕或处决，擅长站位与单体。

首个闭环 DEMO 配置 9 个悟道选项，即 3 条法则 × 3 个动作槽。取得两个同源选项触发一次明显“共鸣”；暂不制作复杂双系合成功法。

## 6. 敌人与遭遇框架

首轮用三种基础敌人验证组合压力：

| 敌人 | 战斗职责 | 核心招式 | 玩家解法 |
|---|---|---|---|
| 尸傀 | 近战追击 | 短前摇突进斩 | 横向闪避后反击 |
| 符傀 | 远程封位 | 扇形符弹 | 穿越弹幕、优先击杀 |
| 石甲妖 | 阵线与破势 | 正面格挡、蓄力砸地 | 绕背或用回程飞剑削定力 |

首个首领建议使用“镇炉猿”：体型大、手臂轮廓清楚，具备扇扫、跃砸、抓取炉石投掷三招；半血后点燃场地边缘并缩短安全区。它验证大体量敌人、范围预警、场地变化和阶段演出，不验证复杂叙事。

## 7. 地图与随机性

- 不随机生成房间内部几何；先制作 6–8 个手工战斗房模板。
- 每局从模板中抽取并排列 5 个房间，随机的是房间顺序、敌群组合、奖励和少量机关。
- 每个房间控制在约 30–90 秒；清场后立即出现奖励，不让玩家扫地找漏物。
- 路线门直接预告下一房主要奖励类型，让随机性产生选择而不是纯运气。
- 首个 DEMO 结构：教学战 → 普通战 → 悟道选择 → 混合战 → 精英 → 补给/悟道 → 首领 → 回府。

## 8. 掉落与经济

战斗中采用“两级掉落”：小掉落保持杀敌快感，主奖励集中在房间结束，避免打断动作节奏。

| 掉落 | 局内作用 | 回府作用 | DEMO 处理 |
|---|---|---|---|
| 灵蕴 | 自动吸附，推动本局悟道 | 无 | 保留 |
| 丹露 | 少量恢复 | 无 | 保留 |
| 灵材 | 无或弱即时价值 | 建设洞府 | 死亡保留一部分，通关全额带回 |
| 残卷 | 解锁/扩充功法池 | 悟道台研究 | 精英和首领掉落 |
| 妖核 | 无 | 设施关键升级 | 首领首通奖励 |

首轮不做装备词条海、背包格子、市场和复杂制作。掉落价值必须能在一局内被玩家理解。

## 9. 洞府框架

洞府承担“长期成长、整备选择、叙事承载、审美表达”四项职责，但首个 DEMO 只实现前三个设施的一级功能：

- **剑炉**：解锁本命飞剑的一种起始变体或招式替换。
- **悟道台**：解锁新的悟道选项，并查看已经发现的法则组合。
- **灵田**：把灵材转化为下一局的一次起始补给选择。

洞府升级优先增加选择和新玩法，不直接叠加永久攻击力。设施必须在场景中可接近、可交互、可见变化；首轮不做自由摆放、离线计时、访客社交和大规模建筑系统。

## 10. 与《哈迪斯》的借鉴边界

借鉴：固定俯视镜头下的清晰战斗、短房间节奏、房间后构筑选择、失败回到安全据点、局内与局外成长互相推动。

不照搬：希腊神赐包装、逃出冥界目标、门奖励图标体系、完整按键结构、角色关系网和内容规模。

本项目必须形成的独特性：飞剑的去程/回程站位、悟道法则共鸣、战利品让洞府产生可见变化，以及巨型妖物与修仙术法对轰的演出。

## 11. 首个 DEMO 推进

### V0：可复现生产工作流

V0 先于所有玩法样片，目标不是证明战斗好玩，而是证明项目能持续生产。

范围：AI Coding 项目约束、Unity/Git LFS 仓库、本地 ComfyUI 图片管线、模型与生成参数溯源、跨主机引导与验证脚本、Notion 专题和任务归档。

通过标准：

- 一台新主机克隆仓库后，能按文档完成 Unity、Codex 和本地图片环境配置。
- 同一模型、工作流与种子可以被重新发起，生成物带有完整溯源侧车文件。
- 原始生成、审核通过资产、模型权重、密钥和本机路径有清晰边界。
- 代码与配置可以通过 Git 共享，研究/决策/任务可以写入并关联到 Notion。
- 当前主机完成一次本地图片生成烟雾测试；第二台主机接入作为远端仓库建立后的验收项。

### Prototype 0：战斗手感样片

目标时长 2–3 分钟，只做一间灰盒竞技场。

范围：45° 镜头、移动、三段普攻、御剑、闪避、受击/死亡、尸傀与符傀、基础命中停顿和镜头反馈。

通过标准：

- 玩家能持续看清自己、敌人前摇和危险区域。
- 普攻、闪避、御剑之间没有明显输入卡顿，关键动作允许合理取消。
- 受到伤害时，玩家能说明自己为什么中招。
- 连续 3 分钟战斗无卡死、穿墙和目标丢失。
- 1080p 目标帧率稳定在 60 FPS。

### Demo 1：一局一府垂直切片

目标时长 8–12 分钟，形成可重复的最小闭环。

范围：6–8 个房间模板中抽取 5 间、3 类基础敌人、1 个精英变体、镇炉猿首领、9 个悟道选项、5 类掉落、洞府 3 个设施的一级交互、存档与第二局解锁。

通过标准：

- 玩家至少能形成两种打法明显不同的 Build。
- 首领会迫使玩家使用移动、闪避、近战和回程御剑，而不是站桩输出。
- 一局结束后，玩家能明确指出战利品改变了洞府的什么，以及下一局想验证什么。
- 连续完成 5 局无阻断性错误，失败与通关都能正确回府并保存长期资源。

### 后置内容

在 V0 通过前不进入 Prototype 0 的正式开发；在 Demo 1 通过前不制作：第二武器、完整剧情、自由建造、多周目境界、市场交易、多人联机、开放世界、复杂程序化地图和大规模美术资产。

## 12. 首轮验证问题

1. 飞剑去程/回程是否足以形成区别于普通双摇杆动作游戏的核心乐趣？
2. 固定 45° 镜头在敌群、弹幕与大首领同时出现时是否仍清楚？
3. 悟道选择是否改变操作决策，而不只是提高 DPS？
4. 怪物死亡掉落与房间主奖励能否兼顾爽感和节奏？
5. 洞府的可见变化能否自然产生“再打一局”的动机？
